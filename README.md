# SkyRush ✈
Mchezo wa ndege (sarafu za bandia). Faili: index.html, manifest.json, sw.js, icon-192.png, icon-512.png

## Kuweka hewani (GitHub Pages)
1. Tengeneza repo mpya GitHub, pakia faili zote hizi (zikiwa mzizi wa repo).
2. Settings → Pages → Source: Deploy from branch → main / (root) → Save.
3. Fungua https://JINA.github.io/REPO/ kwenye Chrome ya simu.
4. Menu ⋮ → "Install app" / "Add to Home screen" (iPhone: Share → Add to Home Screen).
